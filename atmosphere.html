Atmosphere Calculator

Developed in 2019, AtmosphereCalculator is a simple Java-based application that calculates key atmospheric properties—temperature, pressure, and density—based on altitude. It follows standard models up to 47,000 m.

Context

Created for first-year BSc Aerospace Engineering students at TU Delft to assist with atmospheric modeling in assignments and projects.

Features

  • Temperature in K & °C
  • Pressure in Pa
  • Density in kg/m³
  • Java Swing GUI

How to Use (Java)

  1. Clone: git clone https://github.com/joonhaim/AtmosphereCalculator.git
  2. Build & Run: open in IDE → compile → run Main.java
  3. Use: enter altitude, click Calculate, read off T, P, ρ
