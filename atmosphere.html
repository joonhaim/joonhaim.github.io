Atmosphere Calculator

Developed in 2019, AtmosphereCalculator is a simple Java-based application that calculates key atmospheric properties—temperature, pressure, and density—based on altitude. It follows standard atmospheric models and supports calculations from sea level up to 47,000 meters.

Context

This tool was created for first-year BSc Aerospace Engineering students at TU Delft to assist with atmospheric modeling. It enables fast and reliable computations of atmospheric parameters commonly used in academic assignments and engineering projects.

Features

  • Calculate temperature in Kelvin and Celsius
  • Calculate pressure in Pascals at any valid altitude
  • Determine air density in kg/m³
  • Simple and intuitive GUI interface (Java Swing version)

How to Use (Java Version)

  1. Clone the repository: 
    git clone https://github.com/joonhaim/AtmosphereCalculator.git
  2. Build and Run:
    • Open the project in your Java IDE
    • Compile the source code
    • Run Main.java to launch the GUI
  3. Using the App:
    • Input altitude in meters
    • Click Calculate
    • View results for temperature (K and °C), pressure (Pa), and density (kg/m³)
