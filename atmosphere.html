Atmosphere Calculator

Developed in 2019, AtmosphereCalculator is a simple Java-based application that calculates key atmospheric properties—temperature, pressure, and density—based on altitude. It is bassed on the International Standard Atmosphere (ISA) model, and works up to 47,000 m.

Context

Created for first-year BSc Aerospace Engineering students at TU Delft…

Features

  • Calculate temperature in K & °C
  • Calculate pressure in Pa
  • Determine density in kg/m³
  • Java Swing GUI

How to Use (Java)

  1. git clone https://github.com/joonhaim/AtmosphereCalculator.git
  2. Open in IDE → compile → run Main.java
  3. Enter altitude, click Calculate, read T/P/ρ
