1. Purpose

The CH-IQI dashboard aggregates publicly available quality and activity indicators so that clinicians, students, policy analysts, and the public can compare volumes and interpret outcomes across cantons and hospitals. This methodology is designed to keep the pipeline transparent and reproducible.

  • Scope: CH-IQI indicators (latest published year), hospital volumes, and canton-level normalisations.
  • Out-of-scope: causal inference and risk adjustment beyond what the source data already provides.

2. Data Sources

Primary inputs in this release:

  • CH-IQI hospital indicators (2023): Federal Office of Public Health (FOPH). Download via the official open data portal.
  • Population by canton (2023): Federal Statistical Office (FSO). Used to compute per-capita metrics.
  • Reference tables: canton ISO-2 codes, display names, and geometry centroids for mapping.

Tables are joined using canton_code (for example, BE, ZH). Hospital records rely on provider IDs in the CH-IQI export. When a provider operates multiple sites, records are aggregated by the published identifier unless site-level rows are available.

3. Data Cleaning & Integration

  • Format harmonisation: numeric columns coerced to decimal notation, dates parsed to ISO-8601.
  • Deduplication: duplicate rows removed using (year, provider_id, indicator_code) as a composite key.
  • Suppression rules: source redactions (e.g., counts < 10) remain missing; back-calculation is intentionally avoided.
  • Outlier review: extreme rates flagged for manual review but retained when published in the source.
  • Joins: canton population merged to compute per-capita indicators; missing population rows stop the affected calculation for that canton.

Tooling: preprocessing is performed in Python (pandas) and/or JavaScript build steps; final client-side transformations support interactive charts.

4. Indicator Formulas & Aggregations

Each indicator uses a simple, explicit formula so that the dashboard values can be reproduced outside of the UI. Variables shown below match the column names found in the processed dataset.

Indicator formulas
Indicator Formula Notes
Mortality rate (%) mortality_rate = (in_hospital_deaths / discharges) * 100 Discharges exclude day cases if they are not part of the indicator denominator.
Procedures per 100k inhabitants procedures_per_100k = (procedures_total / canton_population) * 100000 Population figures align with the indicator year (e.g., 2023).
Average length of stay (days) average_los = stay_days_sum / discharges Stay days exclude outliers trimmed by CH-IQI source rules.
Readmission rate (%) readmission_rate = (readmissions_30d / discharges) * 100 Readmissions measured within 30 days of discharge where supplied.
Complication rate (%) complication_rate = (complication_events / procedures_total) * 100 Events correspond to CH-IQI adverse event counts.
National weighted average weighted_average = sum(value * weight) / sum(weight) Weights are discharges unless a CH-IQI specification overrides them.

4.1 Aggregations

  • Hospital → Canton: sum volumes by canton; rates are recalculated on canton totals.
  • Canton → Switzerland: per-capita national rates come from canton totals and the summed population.

4.2 Suppressed or missing values

Cells suppressed in the CH-IQI source remain missing in the dashboard. Visualisations indicate missingness with hatching or neutral labels, and missing values are excluded from averages unless explicitly noted.

5. Visualisation Choices

  • Bars support cross-sectional comparisons (for example, canton volumes).
  • Maps show geographic distribution using per-capita shading.
  • Lines illustrate multi-year trends when 2018–2023 data is available.
  • Highlighting: the selected canton is emphasised; other regions are muted to reduce clutter.
  • Scales: zero-based axes for count metrics; rate charts disclose any non-zero baselines.
  • Tooltips: surface raw counts, denominators, and definitions to aid interpretation.

6. Interpretation & Limitations

  • Coverage: the dashboard reflects what is published in CH-IQI; private or non-reporting providers may limit completeness.
  • Case-mix: no additional risk adjustment is applied beyond the source methodology.
  • Small-number volatility: rates derived from small denominators can shift dramatically year to year.
  • Lag: publication occurs with a delay; figures represent the latest year available in the source.
  • Mapping boundaries: canton boundaries are administrative and may not mirror referral patterns.

7. Update Policy

The dashboard targets the most recent CH-IQI release. After each annual publication:

  1. Ingest the new year’s files and refresh joins.
  2. Recompute per-capita metrics using the matching canton population data.
  3. Regenerate charts and spot-check indicator distributions versus the prior year.
  4. Update the “Last updated” label, version tag, and changelog entry.

8. Reproducibility

Processing scripts and configuration live in the project repository. Each release is tagged and pinned to exact data files with checksums. To reproduce locally:

  1. Clone the repository and check out the tag listed below.
  2. Place source CSVs in /data/raw/<year>/ (see the project README for details).
  3. Run the preprocessing script to generate /data/processed/.
  4. Open ch_hospital.html directly or run the local development server for the dashboard.

9. Definitions & Glossary

CH-IQI
Swiss Hospital Quality Indicators published by the Federal Office of Public Health (FOPH).
Discharge
A completed inpatient episode; denominator for several indicators.
Per 100k
Normalisation by canton population to enable cross-canton comparability.
