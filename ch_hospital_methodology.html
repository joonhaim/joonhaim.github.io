CH-IQI 2023 Dashboard

Methodology

This document explains where the Swiss Hospital Interventions (CH-IQI) data originates, how it is processed, and how each indicator is derived before being visualised on the dashboard.

1. Purpose

This dashboard was created as a personal project using a publicly available database from the Swiss Federal Office of Public Health.

The primary purpose of this dashboard is for users to easily browse through the number of cases for different medical procedures in every Swiss hospital.

The intended users are the general public who wants to more easily access this public data.

As this is my first public dashboard, I decided to not include any public statistics regarding quality of care, and kept it simple with purely the number of cases per intervention, per hospital.

2. Data Sources

Hospital procedures (CH-IQI)

Source: The main database used was CH-IQI 2023 by the Swiss Federal Office of Public Health (BAG/OFSP/UFSP): bag.admin.ch.

The CH-IQI dataset is published annually and provides a standardized national set of hospital quality indicators derived from inpatient discharge data.

Population by canton

Data regarding population by canton was taken from the Federal Statistical Office (BFS OFS UST FSO): bfs.admin.ch.

Dataset: Structure of the permanent resident population by canton, 2010–2023.

For the purpose of this dashboard, only the 2023 permanent resident population was used, as the CH-IQI data used was also from 2023.

3. Data Cleaning

The CH-IQI (Swiss Inpatient Quality Indicators) database is published annually. It provides a standardized national set of hospital quality indicators derived from inpatient discharge data. The database is extensive and consists not only of the number of cases for each hospital and medical procedure, but also various categories of quality and process indicators.

Each indicator (e.g., hip replacement, stroke treatment, pneumonia) is defined according to the G-IQI/CH-IQI Version 5.4 specification, which aligns with the German IQM (Initiative Qualitätsmedizin) system.

For each indicator, the dataset typically includes:

  • Observed values — e.g., number of cases, mortality rates, or complication rates.
  • Expected values and standardized ratios (SMR) — for indicators where risk adjustment is possible.
  • Process and complication indicators — e.g., proportion of minimally invasive operations or postoperative complications.
  • Quantitative information — such as case counts per hospital (used in this dashboard).
  • Minimum volume indicators — showing whether a hospital meets required minimum case thresholds for specific procedures.

For this dashboard, only the “information quantitative” component (i.e., number of cases per hospital and procedure in 2023) was used.

The individual procedures are labeled with F codes for the number of cases. The description for each of these F codes is, however, in the respective language region where the hospital is located. I therefore had to manually categorize what language each description was in.

To identify the language of every F-code, I joined the hospital export to the multilingual catalogue published with the CH-IQI 5.4 specifications and generated a lookup table that stores the authoritative German, French, and Italian wordings for each indicator. The lookup lives in static/data/f_code_description_translated.csv, so anyone can audit or reuse the mappings, and a short script flags any descriptions that do not match the table by checking language- specific diacritics before I confirm the categorisation manually. When the Federal Office of Public Health releases a new CH-IQI extract, I download the updated CSV, rerun the extraction script (scripts/generate_f_procedure_dataset.py) together with the language check, and append any new or changed F-codes to the lookup so the categorisation stays current.

4. Indicators and Calculations

The dashboard includes a small set of simple and interpretable metrics. Each indicator is computed directly from the CH-IQI and BFS datasets, using transparent and reproducible formulas.

Indicators used in the CH-IQI Dashboard (2023)
Indicator Definition / Formula Purpose
Hospital case volume count(cases_per_hospital_and_procedure) Shows the total number of procedures performed in each hospital.
Canton total volume sum(hospital_case_volume) by canton Aggregates all hospital cases in a canton for a selected procedure.
Per-capita rate (canton_total_cases / canton_population) × 100 000 Provides regional context by normalising procedure counts by population.
Share of canton volume (hospital_cases / canton_total_cases) × 100 Shows each hospital’s relative contribution within its canton.
National totals sum(canton_total_cases) Summed case counts for the entire country per procedure.
Centralisation HHI Index sum((hospital_share_of_cases)²) Measures concentration of procedure volumes across hospitals (0–1 scale).
University hospital share (cases_university_hospitals / national_total_cases) × 100 Indicates how centralised a given procedure is in tertiary care centres.
Per-hospital share of national volume (hospital_cases / national_total_cases) × 100 Highlights each hospital’s proportion of the total Swiss volume.
Leading hospital Hospital with the highest number of cases for the selected procedure. Identifies the top provider by case count in Switzerland.

5. Limitations

As this is a personal and exploratory project, the dashboard does not include complex statistical modeling or risk-adjusted comparisons.

Language inconsistencies across Switzerland (DE/FR/IT) and differences in hospital reporting may introduce minor errors in categorization.

The dataset reflects 2023 data only and may not represent trends or quality of care indicators.

All values are presented as-is from the public datasets, without any modification beyond cleaning and aggregation.
