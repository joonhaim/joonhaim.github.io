CH-IQI 2023 Dashboard

Methodology

This page explains where the data comes from, how it is cleaned and combined, how indicators are calculated, and how to read the charts.

1) Purpose

The Swiss Hospital Interventions (CH-IQI) dashboard aggregates publicly available quality and activity indicators to help users compare volumes and interpret outcomes across cantons and hospitals. This methodology aims to make the pipeline transparent and reproducible.

  • Audience: clinicians, students, policy analysts, and the public.
  • Scope: CH-IQI indicators (latest published year), hospital volumes, and canton-level normalisations.
  • Out-of-scope: causal inference, risk adjustment beyond that provided in the source data.

2) Data Sources

Primary inputs used in this release:

  • CH-IQI hospital indicators (2023): Federal Office of Public Health (FOPH). Download via official open data portal.
  • Population by canton (2023): Federal Statistical Office (FSO). Used for per-capita metrics.
  • Reference tables: canton codes (ISO-2), names, and geometry centroids for mapping.

Tables are joined using canton_code (e.g., “BE”, “ZH”). Hospital records rely on provider IDs available in the CH-IQI export. If a provider operates multiple sites, records are aggregated by the published identifier unless site-level rows are available.

3) Data Cleaning & Integration

  • Format harmonisation: numeric columns coerced to decimal (dot), dates parsed to ISO-8601.
  • Deduplication: duplicate rows removed by composite key (year, provider_id, indicator_code).
  • Suppression rules: small counts (e.g., <10) preserved as missing per source redaction; no back-calculation attempted.
  • Outliers: extreme rates flagged but retained if present in source.
  • Joins: canton population merged to compute per-capita indicators; missing population rows stop the affected calculation for that canton.

Tooling: preprocessing in Python (pandas) and/or JavaScript build steps; final transformations executed in-browser for interactivity.

4) Indicators & Calculations

4.1 Core formulas

Mortality rate (%)
(In-hospital deaths ÷ Discharges) × 100
Procedures per 100k inhabitants
(Total procedures (canton) ÷ Canton population) × 100 000
Average length of stay (days)
Σ (stay days) ÷ Number of discharges
National average (weighted)
Σ (hospital value × hospital weight) ÷ Σ (hospital weight), where weights are discharges unless otherwise specified by CH-IQI.

4.2 Aggregations

  • Hospital → Canton: sum volumes by canton; rates re-computed on canton totals.
  • Canton → Switzerland: per-capita national rates computed from canton totals and total population.

4.3 Suppressed or missing values

Cells suppressed in the CH-IQI source remain missing in the dashboard. Charts indicate missingness with hatching or a neutral label; missing values are excluded from averages unless explicitly noted.

5) Visualisation Choices

  • Bars for cross-sectional comparisons (e.g., canton volumes).
  • Maps for geographic distribution (per-capita shading).
  • Lines for multi-year trends if available for 2018–2023.
  • Highlighting: the user-selected canton is emphasised; others are muted to reduce clutter.
  • Scales: zero-based axes for count metrics; rate charts disclose any non-zero baselines.
  • Tooltips: show raw counts, denominators, and definitions to aid interpretation.

6) Interpretation & Limitations

  • Coverage: the dashboard reflects what is published in CH-IQI; private or non-reporting providers may limit completeness.
  • Case-mix: the dashboard does not add risk adjustment beyond source methods; hospital comparisons should be contextualised.
  • Small-number volatility: rates from small denominators can be unstable year-to-year.
  • Lag: publication occurs with a delay; figures represent the latest available year in the source.
  • Mapping boundaries: canton boundaries are administrative and may not mirror referral patterns.

7) Update Policy

The dashboard targets the most recent CH-IQI release available. After each annual release:

  1. Ingest new year files and refresh joins.
  2. Recompute per-capita metrics using the same year’s canton population.
  3. Regenerate charts and spot-check indicator distributions versus prior year.
  4. Update this page’s “Last updated”, version tag, and changelog.

8) Reproducibility

Processing scripts and configuration live in the project repository. Each release is tagged and pinned to exact data files with checksums. To reproduce:

  1. Clone the repo and check out the tag listed below.
  2. Place source CSVs in /data/raw/<year>/ (see README).
  3. Run the preprocessing script to produce /data/processed/.
  4. Open ch_hospital.html or run the local server for the dashboard.

9) Definitions & Glossary

CH-IQI
Swiss Hospital Quality Indicators published by the Federal Office of Public Health (FOPH).
Discharge
A completed inpatient episode; denominator for several indicators.
Per 100k
Normalisation by canton population to enable cross-canton comparability.
