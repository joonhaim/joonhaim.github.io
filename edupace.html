EduPace

EduPace is an educational simulator that trains nurses and students to configure a temporary external single-chamber pacemaker. It blends a software ECG and pacing simulator with a tactile control unit so users can practice pacing, sensing, and threshold adjustments in a realistic environment.

Project overview

Developed within the TU Delft Minor Biomedical Engineering, EduPace replicates the behavior of the Medtronic 53401 Temporary External Pacemaker for training scenarios. Learners can safely rehearse device configuration, interpretation, and patient-response adjustments before entering the clinic. The simulator targets the clinical realities of managing bradycardia caused by AV blocks, where dependable ventricular pacing is critical to restore sufficient cardiac output.

Clinical relevance

Models first-, second-, and third-degree AV blocks and the pacing response.

Why temporary pacing training matters

Temporary external pacemakers stabilize patients with bradycardia caused by sinoatrial node dysfunction or atrioventricular (AV) blocks. Because the devices are rarely used on the ward, many nurses do not routinely practice the setup and adjustments needed to respond quickly in emergencies. EduPace bridges this gap by providing a realistic, repeatable learning environment that mirrors real-world pacing workflows.

  • Focus on ventricular pacing to manage AV conduction failures.
  • Reinforces recognition of ECG changes across AV block severity.
  • Simulates capture thresholds and sensing behavior for safer pacing.

System components

The EduPace system combines a browser-based simulator with Arduino-powered hardware to create a blended digital-physical learning environment. Each component is modular, so the platform can evolve with additional scenarios and devices.

  • Web-based ECG and pacing engine with real-time visualization.
  • Arduino GIGA control surface with encoders, buttons, and indicator LEDs.
  • WebSerial connectivity for seamless device-browser communication.
  • Configurable scenarios for instructors and self-paced learning.
Software

Simulator Interface

Electron-packaged web app with dashboards, scenario selection, and real-time ECG feedback that mirrors pacemaker adjustments.

Hardware

Control Unit

Arduino GIGA R1 with a touch display shield, rotary encoders for rate/output/sense, and on-screen LED indicators for pacing and sensing activity.

Design highlights

01

Hardware choices

Arduino GIGA R1 was selected for the display shield compatibility and higher graphics performance compared to the earlier Arduino Mega build.

02

Display upgrade

The 800×480 touchscreen replaces 7-segment displays and reproduces labels, indicators, and lock/power states from the Medtronic 53401.

03

Rotary encoders

Incremental encoders emulate the click-by-click adjustment of rate, output, and sensitivity settings with directional logic.

04

Ergonomic enclosure

The 3D-printed casing was refined to be thin, lightweight, and comfortable for one-handed use in training sessions.

Software architecture

EduPace runs as a cross-platform web application packaged with Electron. The software is modular, separating ECG generation, pacing logic, scenario control, and device communication so new cases and features can be added without reworking the full system.

  • Rational Bézier-Bernstein ECG traces for realistic morphology.
  • Decision-tree pacing logic for rate, sensing, and capture behavior.
  • Serial protocol over USB-C at 115200 baud for reliable updates.
  • WebSerial plug-and-play setup for clinical training rooms.
Communication

Hardware-to-software link

Encoder adjustments send rate/output/sense values to the simulator while software commands drive pacing/sensing LED indicators on the device display.

Interface
