Introduction to Reinforcement Learning

Welcome to the repository for the Introduction to Reinforcement Learning course at Leiden University. This repository contains all assignments, each exploring a different aspect of reinforcement learning: from bandit problems and dynamic programming to model-free and model-based learning.

Assignment 1A – Exploration Strategies in Bandits

Action-value estimation and exploration in multi-armed bandits

Methods: ε-Greedy, Optimistic Initialization, Upper Confidence Bound (UCB)

Includes: Strategy comparison and average reward plots

Assignment 1B – Dynamic Programming

Solving Gridworld using dynamic programming

Methods: Value Iteration, Policy Iteration

Assignment 2 – Model-Free Reinforcement Learning

Learning through interaction without a model of the environment

Algorithms: Q-Learning, SARSA, Expected SARSA, n-step SARSA

Environment: Custom GridWorld + Windy variant

Includes: Learning curves, Greedy policies, Parameter sensitivity analysis

Assignment 3 – Model-Based Reinforcement Learning

Planning with an explicit environment model

Algorithms: Dyna-Q (tabular model plus simulated planning), Prioritized Sweeping (focused planning via priority queue)

Environment: Windy Gridworld (stochastic wind proportion 0.9 & 1.0)

Includes: Learning curves for varying planning depths (n = 0, 1, 3, 5), Pure Q-learning baseline (n = 0), Smooth vs. unsmoothed performance comparison, Runtime benchmarking, Comparison plots: Dyna vs. Prioritized Sweeping vs. Q-learning
