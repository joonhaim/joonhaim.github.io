Neural Computing Project: Food Classification CNN

For the Neural Computing course we engineered a full deep learning pipeline that recognises 91 distinct food categories from a dataset of 67,000 crowd-sourced photographs. The project focused on designing a strong baseline without ImageNet pretraining, exploring how far careful data processing, architectural tweaks, and modern optimisation techniques can push a classic convolutional network.

Beyond the core classifier, we connected the model to a Gemini LLM service that transforms raw predictions into personalised “food profiles”, turning label probabilities into narrative explanations, serving suggestions, and nutrition highlights for end users.

Pipeline Overview

Our system revisits AlexNet with modern training practices to maximise performance on a relatively small, imbalanced dataset. Key components include:

  • Data pipeline: stratified train/validation/test split, class-aware sampling, and rich augmentations (color jitter, random crops, flips) applied with Albumentations.
  • Architecture: streamlined AlexNet backbone augmented with Batch Normalization and dropout regularisation for each convolutional block to stabilise training.
  • Loss & optimisation: Focal Loss mitigated class imbalance while the AdamW optimizer paired with cosine annealing learning rate scheduling accelerated convergence.
  • Training infrastructure: mixed-precision training on A100 GPUs, automatic checkpointing, and Weights & Biases experiment tracking.

The resulting model achieved 52% top-1 accuracy on the held-out test set without any external pretraining, outperforming earlier course baselines by a significant margin.

Gemini-Powered Food Profiles

To make the classifier more engaging we integrated Google's Gemini API. Batch predictions from the CNN are transformed into a short prompt that describes the most likely dishes, their confidence scores, and any dietary tags inferred from class metadata. Gemini then synthesises a concise profile that highlights the dominant cuisine, suggests complementary dishes, and offers nutritional talking points tailored to the user's preferences.

This hybrid workflow demonstrates how discriminative vision models and large language models can collaborate: the CNN grounds the system in visual evidence while the LLM translates probabilities into actionable insights for meal planning applications.
